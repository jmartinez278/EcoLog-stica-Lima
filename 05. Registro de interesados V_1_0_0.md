## 3. Estrategia de Gestión y Comunicación

| Grupo | Frecuencia | Formato | Tipo de información |
|---|---|---|---|
| Gerencia General / Patrocinador y Director de Proyecto | Semanal | Reunión de avance + reporte corto | Estado de iteración, riesgos, decisiones clave |
| Equipo docente | Al cierre de cada iteración | Entregable formal (documento/presentación) | Cumplimiento de rúbrica, avance del MVP |
| Equipo de desarrollo | Diaria / semanal | Stand-up breve + tablero Kanban | Tareas, bloqueos, avance técnico |
| Conductores y Operaciones | Al cierre de cada iteración con demo funcional | Demo del "modo conductor" + encuesta corta | Usabilidad, funcionalidad relevante para su trabajo diario |
| Clientes finales | Al final del proyecto (o antes si se valida con datos simulados) | Resumen de beneficios (cumplimiento de entregas, ahorro) | Impacto esperado del sistema en el servicio |
| Municipalidad / MTC y proveedor de API | Solo si aplica (consulta normativa o técnica puntual) | Comunicación formal por correo | Verificación de cumplimiento normativo o técnico |
| Comunidad local y proyectos de reforestación | Ocasional, informativo | Nota informativa o reporte de sostenibilidad | Impacto ambiental del proyecto (CO₂, plan de compensación) |
